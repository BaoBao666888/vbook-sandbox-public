# vBook Sandbox

App Android ARM64/32 chạy bản sao ứng dụng trong sandbox không root, giữ nguyên APK và
chữ ký gốc. VBook được ưu tiên tối ưu. Package host: `bao.vbooksandbox`. Ưu tiên Android12/API31.

- Nhập APK/APKS/split hoặc sao chép bộ APK đã cài.
- Điều khiển dừng/thoát, Google setup và module có tài liệu trong app.

Thư mục này chỉ chứa tài liệu phát hành công khai.

Xem ghi chú từng bản trong `notes`, quyền riêng tư trong `PRIVACY.md` và giấy phép
thư viện trong `licenses`. Bản package mới cài song song bản cũ, chưa có migration
dữ liệu tự động.
